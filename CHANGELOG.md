# Changelog

## 1.0.0 — 2026-09-24

First release of the rebuilt local-first TodAI application.

- Added tasks, notes, ideas, projects, Inbox capture, shared tags, and search.
- Added task progress, completion feedback, filtering, and state history.
- Added Ask Tod with constrained tools, visible activity, approval controls,
  and pinned or temporary chat layouts.
- Added embedded SQLite storage, optional PostgreSQL server mode, migrations,
  and JSON/Markdown export.
- Added responsive navigation, custom controls, settings, and optional seasonal
  presentation.

## 0.1.0 — Legacy prototype

Preserved the original Next.js, Prisma, and MySQL prototype before the TodAI
rebuild was imported into this repository.
